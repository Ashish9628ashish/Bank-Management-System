 Bank Management System 

 About Project
This is a simple Bank Management System developed using Core Java. It allows users to perform basic banking operations.

 Features
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Balance
- View Account Details

 Technologies Used
. Java
. OOP Concepts
. ArrayList
. Scanner

How to Run

1. Clone or download the repository.
2. Open the project in your Java IDE.
3. Compile the Java files.
4. Run `Main.java`.
